# Transformer Language Translation

This project implements a transformer-based model for language translation using a simple and efficient workflow.

## Project Overview
This repository contains a Jupyter Notebook that runs a transformer-based language translation model. The notebook includes data preprocessing, model training, and inference in a single, streamlined workflow.

## Features
- Transformer-based neural machine translation.
- Simple execution by running the provided notebook.

## Repository Structure
```
Transformer-Language-Translation/
│── data/                
│── eng_to_french.ipynb/           # Jupyter Notebook for the data cleaning and preprocessing, model training and testing.
```

## Running the Project
1. Clone the repository:
   ```bash
   git clone https://github.com/HashemAhmed560/Transformer-Language-Translation.git
   cd Transformer-Language-Translation
   ```
2. Open Jupyter Notebook:
   ```bash
   eng_to_french.ipynb
   ```
   Then navigate to the ` eng_to_french.ipynb ` where you installed and open it.

3. Run all cells in the notebook to preprocess data, train the model, and perform translation(make sure the Data is in the same folder as the notebook).
